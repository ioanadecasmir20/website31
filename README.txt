Hosting
-------
The package includes .nojekyll and directory-based index.html files, so it works cleanly on GitHub Pages and standard web hosting when uploaded to the web root.

Images
------
All supplied images are included in assets/images and renamed descriptively.

Contact form
------------
The form is styled and validated but no email account or backend endpoint was supplied. Connect #contactForm to your chosen form processor or server endpoint before expecting web submissions to be delivered.

Compliance wording
------------------
The site avoids claims of guaranteed results and avoids stating that licence-linked security qualifications can be completed fully online. Current SIA / awarding-organisation requirements should be checked before publishing exact regulatory claims.
